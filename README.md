# SaberPlus — descargas de prueba

Versión de prueba de **SaberPlus** para Android, la app para preparar el ICFES Saber 11.

## Cómo instalarla

1. Entra a **[Releases](../../releases/latest)** y descarga el archivo `SaberPlus-prueba.apk`.
2. Ábrelo en el celular. Si Android lo pide, permite **instalar apps de esta fuente**.
3. Abre SaberPlus y entra con la cuenta de prueba que te compartieron.

> La primera vez que abras la app, el servidor de pruebas puede tardar 1 o 2 minutos en responder.

Esta es una versión de prueba. Los datos que guardes pueden borrarse.
